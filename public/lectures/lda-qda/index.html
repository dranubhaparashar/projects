LDA & QDA

Linear and Quadratic Discriminant Analysis

Both methods picture every class as a bell-shaped cloud of points, then assign a new point to the cloud it most likely came from. They differ in one assumption about the shape of those clouds, and that assumption decides whether the boundary between classes is a straight line or a curve.

Type
Generative classifier
Built on
Bayes' theorem + the normal distribution

Why discriminant analysis?

Classification means predicting a category \(Y\) (spam or not, which disease, which grape) from measurements \(X\). There are two broad ways to build a classifier.

Discriminative models, like logistic regression, learn \(P(Y \mid X)\) directly: they look only for the boundary. Generative models learn how each class produces its data, \(P(X \mid Y)\), and then use Bayes' theorem to turn that around into \(P(Y \mid X)\). LDA and QDA are generative. They assume each class's data follows a multivariate normal (Gaussian) distribution.

When they beat logistic regression

  • Classes are well separatedLogistic regression's coefficients become unstable and can run off to infinity when the classes barely overlap. LDA's estimates stay finite and stable.
  • Small samplesIf the features are roughly normal within each class, LDA uses that structure and needs less data to reach a good boundary.
  • More than two classesLDA and QDA handle K classes natively with one formula. There is no need to combine several one-vs-rest models.
  • You want to see the dataLDA doubles as dimensionality reduction. It can squeeze many features down to K−1 axes that best separate the classes, which you can plot.

Why we need both

LDA assumes every class has the same covariance matrix, meaning the same spread and orientation. QDA lets every class have its own. This is the classic bias–variance trade-off:

LDA is rigid. If the classes really have different shapes it is biased, but it has few parameters, so its estimates barely change from one sample to the next (low variance).
QDA is flexible. It can fit different shapes (low bias), but it must estimate a full covariance matrix for every class, so with little data its boundary swings around (high variance).

The shared foundation: Bayes' theorem

LDA and QDA follow the same four-step recipe. Only step 2 differs.

  1. Prior: how common is each class?
    \[ \pi_k = P(Y = k) \approx \frac{n_k}{n} \]
    Read it as: the share of training points that belong to class \(k\).
  2. Likelihood: how does each class generate data?
    \[ f_k(x) = \frac{1}{(2\pi)^{p/2}\,|\Sigma_k|^{1/2}} \exp\!\left( -\tfrac{1}{2}\,(x-\mu_k)^{\top}\,\Sigma_k^{-1}\,(x-\mu_k) \right) \]
    Read it as: a bell-shaped cloud centred at the class mean \(\mu_k\), with shape set by the covariance matrix \(\Sigma_k\). The term in the exponent is the Mahalanobis distance: distance measured in units of the cloud's own spread. LDA forces every \(\Sigma_k\) to be the same \(\Sigma\); QDA does not.
  3. Posterior: flip it with Bayes' theorem
    \[ P(Y = k \mid X = x) = \frac{\pi_k\, f_k(x)}{\sum_{l=1}^{K} \pi_l\, f_l(x)} \]
    Read it as: how common the class is, times how well it explains \(x\), divided by the same quantity summed over all classes so the probabilities add to 1.
  4. Decide: pick the most probable class
    \[ \hat{y}(x) = \arg\max_k \; \delta_k(x), \qquad \delta_k(x) = \log \pi_k + \log f_k(x) + \text{const} \]
    Read it as: the denominator is the same for every class, so we compare only the numerators. Taking logs turns products into sums. The resulting score \(\delta_k(x)\) is called the discriminant function. This rule is the Bayes classifier: if the Gaussian assumption is true, no other rule makes fewer mistakes on average.
Linear Discriminant Analysis

How LDA works

Assumption: every class is a Gaussian with its own mean but one shared covariance matrix: \(X \mid Y=k \sim \mathcal{N}(\mu_k, \Sigma)\). All clouds have the same shape and tilt; they are only shifted.

Training: three estimates

\[ \hat\pi_k = \frac{n_k}{n}, \qquad \hat\mu_k = \frac{1}{n_k}\sum_{i:\,y_i=k} x_i, \qquad \hat\Sigma = \frac{1}{n-K}\sum_{k=1}^{K}\;\sum_{i:\,y_i=k} (x_i-\hat\mu_k)(x_i-\hat\mu_k)^{\top} \]
Read it as: class shares, class averages, and one pooled covariance that averages the spread of all classes around their own means.

The discriminant function

\[ \delta_k(x) = x^{\top}\Sigma^{-1}\mu_k \;-\; \tfrac{1}{2}\,\mu_k^{\top}\Sigma^{-1}\mu_k \;+\; \log \pi_k \]
Read it as: a weighted sum of the features plus a constant. That is a linear function of \(x\), which gives the method its name.

Why the boundary is a straight line

Expand the exponent of the Gaussian:

\[ (x-\mu_k)^\top\Sigma^{-1}(x-\mu_k) = x^\top\Sigma^{-1}x - 2x^\top\Sigma^{-1}\mu_k + \mu_k^\top\Sigma^{-1}\mu_k \]

The first term \(x^\top\Sigma^{-1}x\) is identical for every class, because \(\Sigma\) is shared. When we compare two classes it cancels, and the log-odds are linear in \(x\):

\[ \log\frac{P(Y=k\mid x)}{P(Y=l\mid x)} = \underbrace{\log\frac{\pi_k}{\pi_l} - \tfrac12(\mu_k+\mu_l)^{\top}\Sigma^{-1}(\mu_k-\mu_l)}_{\text{constant}} \;+\; x^{\top}\underbrace{\Sigma^{-1}(\mu_k-\mu_l)}_{w} \]
Read it as: the boundary is where this equals 0, the set of points with \(w^\top x = \text{constant}\). In 2D that is a line; in 3D a plane; in general a hyperplane.

Fisher's view: LDA as the best projection

Fisher (1936) asked a different question and reached the same answer. If we must squash the data onto a single line, which direction keeps the classes most separated? He scored a direction \(w\) by the distance between projected class means relative to the spread inside each class:

\[ J(w) = \frac{w^{\top} S_B\, w}{w^{\top} S_W\, w} = \frac{(\text{gap between projected means})^2}{\text{spread within classes}}, \qquad w^{*} \propto S_W^{-1}(\mu_2 - \mu_1) \]
Read it as: \(S_B\) is the between-class scatter and \(S_W\) the within-class scatter. The best direction \(w^*\) is the mean difference, corrected by the inverse of the within-class spread. That is the same \(w\) as in the boundary formula above. With \(K\) classes, LDA finds up to \(K-1\) such axes.

Quadratic Discriminant Analysis

How QDA works

Assumption: every class is a Gaussian with its own mean and its own covariance matrix: \(X \mid Y=k \sim \mathcal{N}(\mu_k, \Sigma_k)\). One class can be tight and round while another is wide and tilted.

Training: one covariance per class

\[ \hat\pi_k = \frac{n_k}{n}, \qquad \hat\mu_k = \frac{1}{n_k}\sum_{i:\,y_i=k} x_i, \qquad \hat\Sigma_k = \frac{1}{n_k-1}\sum_{i:\,y_i=k} (x_i-\hat\mu_k)(x_i-\hat\mu_k)^{\top} \]
Read it as: the same as LDA, except each class keeps its own covariance instead of pooling.

The discriminant function

\[ \delta_k(x) = -\tfrac{1}{2}\log|\Sigma_k| \;-\; \tfrac{1}{2}(x-\mu_k)^{\top}\Sigma_k^{-1}(x-\mu_k) \;+\; \log\pi_k \]
Read it as: three parts. A penalty for a wide class (\(\log|\Sigma_k|\) grows with spread), the squared Mahalanobis distance to that class, and the prior. A broad class must "spread its probability thin", so it pays for being broad.

Why the boundary curves

The term \(x^\top\Sigma_k^{-1}x\) now differs from class to class, so it no longer cancels when we compare two classes. The boundary \(\delta_k(x)=\delta_l(x)\) is a quadratic equation in \(x\):

\[ x^{\top}\underbrace{\left(\Sigma_l^{-1}-\Sigma_k^{-1}\right)}_{\text{does not vanish}}x \;+\; b^{\top}x \;+\; c \;=\; 0 \]
Read it as: in 2D the boundary can be an ellipse, a parabola, a hyperbola or a pair of lines, depending on how the two covariance matrices differ.

The cost of that flexibility: each \(\hat\Sigma_k\) has \(p(p+1)/2\) numbers to estimate, and it can only be inverted if the class has more than \(p\) training points. With 50 features, every class needs at least 51 samples, and in practice many more.

Worked example by hand

Eight points, two classes, two features. We classify the new point \(x^* = (3, 6)\) with both methods. The arithmetic is small enough to check on paper, and the two methods disagree.

ClassPoints (x₁, x₂)
A(2,3) (3,4) (4,3) (3,2)
B(5,6) (7,8) (9,6) (7,4)
newx* = (3,6)
  1. 1 · Priors and means
    \( \pi_A=\pi_B=0.5,\quad \hat\mu_A=(3,3),\quad \hat\mu_B=(7,6) \)
  2. 2 · Class covariances
    \( \hat\Sigma_A=\begin{pmatrix}0.667&0\\0&0.667\end{pmatrix},\quad \hat\Sigma_B=\begin{pmatrix}2.667&0\\0&2.667\end{pmatrix} \)

    B is four times as spread out as A (variance 2.667 vs 0.667).

  3. 3 · LDA: pool them
    \( \hat\Sigma=\frac{3\hat\Sigma_A+3\hat\Sigma_B}{8-2}=\begin{pmatrix}1.667&0\\0&1.667\end{pmatrix},\quad \hat\Sigma^{-1}=0.6\,I \)
  4. 4 · LDA scores
    \( \delta_A(x)=1.8x_1+1.8x_2-5.4,\qquad \delta_B(x)=4.2x_1+3.6x_2-25.5 \)

    The \(\log 0.5\) terms are equal and dropped. Boundary: \(\delta_A=\delta_B \Rightarrow 4x_1+3x_2=33.5\).

  5. 5 · LDA at x* = (3, 6)
    \( \delta_A=10.8,\quad \delta_B=8.7 \;\Rightarrow\; P(A\mid x^*)=\frac{1}{1+e^{-2.1}}=0.891 \)
  6. 6 · QDA at x* = (3, 6)
    \( \delta_A=-\tfrac12\ln\tfrac49-\tfrac12\cdot1.5\cdot(0^2+3^2)=0.405-6.75=-6.345 \)
    \( \delta_B=-\tfrac12\ln\tfrac{64}{9}-\tfrac12\cdot0.375\cdot(4^2+0^2)=-0.981-3=-3.981 \)
    \( \Rightarrow\; P(B\mid x^*)=\frac{1}{1+e^{-2.364}}=0.914 \)

Choose LDA when

  • training data is limited relative to the number of features
  • the classes look like shifted copies of each other
  • you need a simple, explainable model or a 2D plot of the classes

Choose QDA when

  • you have plenty of data in every class
  • the classes clearly differ in spread or orientation
  • a straight boundary visibly misses the shape of the data

Related methods

  • Regularized DAFriedman (1989) blends the two: \(\hat\Sigma_k(\alpha) = \alpha\hat\Sigma_k + (1-\alpha)\hat\Sigma\). At \(\alpha=0\) it is LDA, at \(\alpha=1\) QDA. Choose \(\alpha\) by cross-validation. In scikit-learn, QDA's reg_param and LDA's shrinkage do similar jobs.
  • Gaussian Naive BayesQDA with diagonal covariance matrices: it assumes features are independent within each class. Far fewer parameters, so it copes with many features.
  • Logistic regressionProduces the same linear form of log-odds as LDA but fits it directly. More robust when the features are clearly not normal; less efficient when they are.

Build it yourself in Python

wine_lda_qda.py
from sklearn.datasets import load_wine
from sklearn.model_selection import train_test_split, cross_val_score, StratifiedKFold
from sklearn.discriminant_analysis import (LinearDiscriminantAnalysis,
                                           QuadraticDiscriminantAnalysis)
from sklearn.metrics import accuracy_score, confusion_matrix

X, y = load_wine(return_X_y=True)        # 178 wines x 13 measurements
X_tr, X_te, y_tr, y_te = train_test_split(
    X, y, test_size=0.3, stratify=y, random_state=42)

cv = StratifiedKFold(5, shuffle=True, random_state=42)
for name, model in [("LDA", LinearDiscriminantAnalysis()),
                    ("QDA", QuadraticDiscriminantAnalysis())]:
    model.fit(X_tr, y_tr)
    pred = model.predict(X_te)
    print(name, "test accuracy:", round(accuracy_score(y_te, pred), 3))
    print(confusion_matrix(y_te, pred))
    scores = cross_val_score(model, X, y, cv=cv)
    print(name, "5-fold CV:", round(scores.mean(), 3))

# LDA as dimensionality reduction: 13 features -> 2 axes
lda = LinearDiscriminantAnalysis().fit(X_tr, y_tr)
Z = lda.transform(X)                   # plot Z[:, 0] against Z[:, 1]
print(lda.explained_variance_ratio_.round(3))

Wrap-up

Key takeaways

  • Both methods model each class as a Gaussian and classify with Bayes' theorem: pick the class with the highest posterior probability.
  • LDA shares one covariance across classes. The quadratic term cancels, so the boundary is linear.
  • QDA gives each class its own covariance. Nothing cancels, so the boundary is quadratic.
  • The choice is a bias–variance trade-off. LDA for small data or similar class shapes; QDA for large data with clearly different shapes.
  • LDA also reduces dimensions to at most K − 1 axes, which is why 13 wine measurements fit on one 2D map.

Check your understanding

Two classes have the same mean, but one is far more spread out. Which method can separate them?

QDA. LDA's boundary depends on the difference between means; with equal means it has nothing to work with and does no better than guessing. QDA uses the different covariances and draws a closed curve around the tight class. Try the "Same centre" preset in the playground.

You have 20 features, 3 classes and 15 samples per class. Which method is safer?

LDA. QDA would need a 20 × 20 covariance matrix (210 numbers) for each class from only 15 points. With \(n_k \le p\) that matrix cannot even be inverted. LDA pools all 45 points into one estimate.

Why is LDA's decision boundary a straight line?

Because every class shares the same \(\Sigma\), the term \(x^\top\Sigma^{-1}x\) is identical for every class and cancels when two classes are compared. What remains is linear in \(x\).

How many discriminant axes can LDA produce for 3 classes and 13 features?

At most \(\min(K-1, p) = 2\). Three class means always lie in a plane, so two axes capture all the separation between them.
